# ADR 0009：选集、广告回拖、跨设备记录与换源集序号

## 状态与来源

产品决定已接受；实现与回归覆盖尚待核验，不代表下述行为已经全部实现。

依据：用户于 2026-10-28 04:20 UTC 明确确认的四项行为。本文件为这些决定的单一权威记录；[REVIEW.md](../../REVIEW.md) 引用验收要求，审计报告仅作摘要。工程推导和待设计内容单列，不当作用户原话。

## 用户明确决定

1. **暂停后主动选集可以开始自动播放流程。** 新选集不必继承之前的暂停意图。本决定针对主动选集，不扩展为所有后台恢复或自动换源均可取消暂停。
2. **主动回拖到广告区，应再次检测并跳过。** 不能仅因该广告已经跳过一次，就永久抑制回拖后的检测/跳过。这取代此前讨论中“已跳过不再重复”的假设；主动回拖不等于明确点击广告撤销。
3. **跨设备保留最新用户操作记录。** 较新的用户操作可以是回拖到较早时间，因此不能一律用最大播放时间替代“最新操作”。最新操作不等于最后到达服务端的请求。
4. **换源保持相同集序号。** 原源播放第 N 集，换源后选择目标源第 N 集。不同线路在内容、剪辑或编排上的差异，由用户发现后重选；不以跨源内容语义匹配作为自动换源前置条件。

## 工程推导与兼容边界

- 主动选集应产生新的播放意图。浏览器拒绝 autoplay 时，保留可恢复的点击播放入口，不能把拒绝视为线路故障并循环换源；这是实现上述流程的工程要求，不是承诺浏览器必定自动播放。
- “源内集序号稳定”与“跨源按序号切换”兼容：搜索、详情及历史入口对同一源的第 N 项应一致；重复 URL 不应去重挪位，无效项不应使后续集数前移。是否用不可播占位或显式 ordinal 字段实现，仍由设计确定；不要求跨源剧情/标题语义对齐，也不自动按标签重排特别篇。
- 真实片源内容有误时，应区分“应用选错序号/URL”和“源第 N 集本身内容不同”。验收不能把前者归咎于线路，也不能要求应用替后者自动匹配剧情。
- 广告检测继续遵守 [ADR 0004](0004-crowd-sourced-recoverable-ad-skip.md) 的候选、信任和撤销机制；再次检测不是任意扩大广告范围。如何使回拖后重检与 seek-settled、恢复互斥、窗口撤销协调，需在实现前确定时序，防止重复 seek 循环。明确撤销后的抑制作用域仍待设计。
- **建议技术边界，尚未单独确认为产品决定**：目标源缺第 N 集时提示缺集并允许重选，不静默切到其他集。此次按同序号的决定不等于用户明确指定了缺集提示样式或 fallback 流程。
- 本 ADR 不改变 [ADR 0007](0007-segment-scaled-escape-and-recovery-disclosure.md) 的明确用户意图优先原则，也不重新引入原生 HLS 或代理播放主路径。

## 跨设备排序仍需设计

产品目标已明确，具体协议未选定，当前系统也未被证明满足该目标。下一阶段需设计并评审：

1. 哪些动作构成可排序的用户操作；heartbeat、自动续播/跳广告/恢复是否以及如何继承所属操作，不能把后台保存误当新的用户操作。
2. 操作身份、设备/会话标识、同设备顺序、跨设备排序依据及并发并列处理；不能仅凭客户端时间戳或服务端请求到达顺序作保证。
3. 时钟偏差、离线操作、迟到/重试/重复请求的接纳和幂等规则，以及无法确定先后的处理方式。
4. 存储原子比较与更新、服务端返回实际接受的记录/版本、本地乐观缓存校准；覆盖实际承诺支持的后端。
5. 删除历史是否形成屏障及墓碑生命周期、旧设备在途保存与重新观看的关系；用户此次没有决定删除协议。
6. content-key/legacy 双写、旧客户端、迁移与回滚的兼容范围；同序号换源不自动决定跨源时间点比例映射或内容键碰撞的处理。

以上不是指定采用某种复杂时钟、CAS 或日志方案。选择应以现有存储能力和最小可验证协议为依据。

## 应建设或补强的回归场景

以下是目标覆盖，不是已实现或已通过的结果；优先复用现有 PlayPage、Session 和存储测试入口。

| 决定/边界  | 应验证的场景                                                                                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 暂停后选集 | 暂停第 N 集后主动选择第 M 集，开启新播放流程；autoplay 拒绝后点击可恢复；旧暂停/媒体回调不得覆盖新意图                                                        |
| 广告回拖   | 正常跳过后主动回拖到同一广告区，再检测并按规则跳过；恢复/seek-settled 交叉下无无限 seek；明确 undo 单独测试，不能与普通回拖混同                               |
| 最新操作   | 设备 A 旧操作较晚到达、设备 B 新操作较早到达；新操作回拖仍能胜出；heartbeat、重试和重复请求不夺取新操作所有权；时钟偏差/离线/删除场景待排序协议确定后补齐预期 |
| 同序号换源 | 第 2 集换源后仍选择目标源第 2 项，不增加语义匹配门槛；重复 URL/无效项不造成源内序号漂移；目标源内容不同允许用户重选；缺集场景先按上文建议边界讨论并补验       |
