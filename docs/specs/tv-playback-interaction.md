# TV 播放交互基线

记录日期：2026-10-05

本规范记录创维 Q7F Pro 真机验证结果。后续 TV Mode 改造必须以此为回归基线；桌面键盘模拟不能替代电视真机验收。

## 验证环境

- 电视：创维 Q7F Pro
- 系统：Android 13
- 浏览器内核：Chromium `101.0.4951.61`
- User-Agent 设备标识：`8R710_Q7FP`
- 屏幕：`1280 × 720 @ 1.5x`
- 浏览器估算内存：`4 GB`
- 第三方浏览器显示工具栏时，实测视口可能缩至 `1280 × 378`
- HLS：同域 HLS 样片可通过 hls.js 播放，实测 `1920 × 1080`

## 遥控器事件矩阵

| 操作         | 真机行为                                                                                       | TV Mode 要求                                           |
| ------------ | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| 方向键       | 产生标准 `keydown/keyup`，键值为 `ArrowLeft/Right/Up/Down`                                     | 只移动 DOM 焦点，不得触发控件操作                      |
| 长按方向键   | 连续产生 `keydown`，但 `repeat` 始终为 `false`                                                 | 不依赖 `repeat` 判断长按                               |
| 确认键       | 部分场景产生 `Enter(13) + click`                                                               | 当前焦点控件只执行一次                                 |
| 虚拟鼠标确认 | 不产生 `Enter`，产生固定坐标 `653 × 612` 的 `pointer/touch/mouse/click`，且 `pointerType` 为空 | 点击目标与当前焦点不一致时，重定向到当前焦点控件       |
| 返回键       | 未观察到 `Escape`、`BrowserBack`、`keyCode 4`、`popstate` 或 `pagehide`                        | 浮层必须监测焦点逃逸并自行关闭；标准返回键事件仅作增强 |

## 已验证的交互规则

1. 方向键聚焦“播放、换源、设置、选集”等控件时，不记录为点击，也不执行操作。
2. 确认键的固定坐标落到其他控件时，实际执行当前焦点控件，不能误触“播放历史”。
3. 浮层打开后，确认键仍作用于浮层内当前焦点。
4. 浮层焦点逃到底层 UI 时，立即关闭浮层并把焦点恢复到打开浮层的入口。
5. 原生可聚焦元素优先使用 `button`、`a[href]`；禁用控件不得成为确认键重定向目标。
6. TV Mode 的方向键不得继续触发 Web Mode 的快进、快退和音量快捷键。
7. TV Mode 必须将 ArtPlayer 原生播放、进度、下一集、全屏和跳广告控件增强为可聚焦控件，不得再叠加第二套全屏控制层或在播放器下方重复展示播放快捷按钮。
8. TV Mode 的播放区、选集和线路使用上下结构；选集与线路面板占据页面全宽，不能压缩在播放器右侧。
9. 进入全屏后保持或恢复 ArtPlayer 原生控件焦点；进度条获得焦点后，左右键每次快退或快进 10 秒；控制栏按钮的左右键导航由 TV Mode 接管，必须能从左侧播放/下一集连续移动到右侧跳广告、投屏、设置和全屏，确认键执行当前控件。
10. 全屏原生控制栏隐藏或失去焦点后，任一方向键先唤回控制栏并恢复上次播放器控件焦点；该次按键不同时执行移动或快进快退。

## 播放能力结论

- 电视浏览器能够通过 hls.js 播放 HLS。
- 首次使用 Apple 外部样片时出现 `networkError / manifestLoadError`，这是清单网络加载失败，不能判定为解码失败；改用同域样片后成功播放。
- 同域 8 秒样片首帧约 `5411 ms`，分辨率保持 `1920 × 1080`，统计到 `3` 次卡顿、`1 / 238` 掉帧。
- 短样片出现过低缓冲 `bufferStalledError`，但成功起播并完成播放；该错误不能单独判定为解码失败。
- 用户在第三方电视浏览器播放实际内容时，1080P 基本流畅。

## 回归清单

- 从播放页显式进入、退出 TV Mode，原播放源和集数不重置。
- 方向键只改变焦点；确认键只执行焦点控件。
- 依次验证播放/暂停、收藏、选集、换源、设置和全屏。
- 选集或换源浮层打开后按返回键，浮层关闭且焦点回到入口。
- 固定坐标虚拟鼠标确认不会误触其他控件。
- Web Mode 原有鼠标、触摸、快捷键和播放行为不变。

## 开发调试入口

- `/tv-test`：HLS 解码与播放诊断。
- `/tv-remote-debug`：仅开发环境可用的遥控器事件、焦点和虚拟鼠标诊断。

调试页用于复现和采集证据；正式播放页的 TV Mode 才是最终验收对象。
